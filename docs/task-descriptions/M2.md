# M2 — Authentication and User Management

**Purpose:** Establish secure identity, session, role, ownership, and profile capabilities for all user types.

**Task count:** 10

**Status:** Complete — registration, JWT/refresh sessions, role authorization, profile APIs, secure admin bootstrap, collector provisioning, protected frontend routes, and negative-path tests are implemented.

## M2 implementation evidence

- Flyway `V2__authentication.sql`, BCrypt hashes, hashed rotating refresh sessions, and stateless JWT authentication.
- Resident registration/login/profile UI plus role-aware resident and administrator workspaces.
- Administrators are provisioned only through explicit bootstrap environment variables; collectors are created through an admin-only endpoint.
- Integration tests cover unauthorized role access and resident record ownership.
